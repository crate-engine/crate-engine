01 · Start from scratch

One line installs everything — you bring the crew

Crate Engine ships the crate; the AI agents in it are yours. It never installs an agent and never signs into one — it detects what's already on your Mac and offers it for staffing. Your accounts stay yours, always.

Before you install — once per agent, its own way

AgentGet ready
clauderun it in a terminal, finish its one-time setup, sign in with your Claude subscription, then /exit
pirun it, /login with ChatGPT (DeepSeek seats take its API key), quit
codexrun it, sign in with your ChatGPT account, quit

Only the agents you want on the team — any subset works; the app offers what it finds.

The install line · paste into Terminal, press Enter

curl -fsSL <your install link> | bash  # the link ships with this manual

Four numbered steps run (cmux · node · the engine · the crate command — long ones print dots so you can see life), then a short “Your AI agents” report tells you exactly what was detected. Then the app launches itself: a cmux window appears and the app page fills it. First-ever cmux launch may show a welcome window — click through it once.

That's the only terminal command of day one. Everything from here is clicks.

02 · First run

The wizard: five screens, five clicks

WELCOME → STAFF → ATTACH → ARM → CHECK → BOOT

Staff your team

Click Staff your team & start building. The top card shows your detected agents; below, each seat has a tested default model with an honest note on how it bills (flat-rate on your subscription vs metered). Click Save defaults — set once, every project uses them — then Continue → attach a project.

Attach a project

Attach a folder you already have, or Start a new project (Browse… has a ＋ New folder button — no Finder needed). Click Show me what will be added, read the two honest lists (what goes in your repo, what stays local), then Looks right — attach the team.

Arm your team

One-time big downloads some seats need (e.g. QA's browser). If a box appears, click Install now (recommended) and watch the per-tool progress; otherwise it says “Nothing to download.” Then Continue → final check.

Final check

A wiring once-over. Green = good · grey = optional · amber shows the one line that fixes it. If an agent's sign-in has gone stale, this is where it's caught — before a dead boot, with the exact fix.

Boot the team

Click Boot the team →. A new cmux workspace opens with five panes and every seat boots its harness. The Orchestrator reads its brief, verifies its teammates, onboards them, and greets you: “the rig is up — what shall we build first?”

If Boot refuses: that's the app protecting you — the message names which agent isn't ready and exactly what to run. Fix it, click Boot again.

03 · Directing your team

Talk to the Orchestrator — hold the gates

Click into the Orchestrator pane and say what you want, like a message to a team lead:

Example direction

“Build me a small feature: add a footer line to the app's main page that says Built by my AI team with the current year. Run your full process and hold at the merge gate for my go.”

Then watch: the Coder implements on a branch, a build gate verifies it, and the Reviewer and QA check it in parallel — static review and runtime proof at once. You do nothing until the Orchestrator reports it's HOLDING at the merge gate with both verdicts.

Your one decision

Reviewer says APPROVED and QA says PASS? Type “Merge it.” — the only thing that ever merges code. An approval alone never does; the gate is yours.

04 · Day 2 and every day after

Stopping is nothing; coming back is one line

Everything lives on disk — the project, your staffing, the team's state. When you're done, just close the cmux window. Optionally tell the Orchestrator .checkpoint first to bank a tidy save.

Several projects on one Mac

crate open is project-anchored: run inside a project folder, it opens that project — never a guess. Run it from another project's folder and the app switches to it. A bare crate open anywhere else reopens your most recent project.

The welcome screen remembers too

With a project attached, Welcome shows “Continue where you left off” with the project path and a Continue → Boot the team button. You never re-walk the wizard for a project you already have.

05 · Keeping it healthy

The Boot screen is your live dashboard

After boot, the same screen watches every seat. Each row shows who's staffed, whether the pane is live, and how fresh its state file is.

The three states you'll see

DotMeaningWhat to do
● livethe seat's pane is up and runningnothing
● signed-outthe harness runs but its sign-in went stale (common after a machine sits overnight)click Relaunch — a fresh launch picks up the renewed sign-in
● deadthe pane is gone (closed or crashed)click Relaunch — a fresh pane comes back walled and oriented

Bigger hammers, still one click

Refresh team (relaunch all)relaunches every seat, Orchestrator last — the full morning-after reset
Update now (your customizations survive)on Welcome when an engine update is available; fast-forwards the engine, checks your customizations, asks for one app restart

If the whole app window is gone (workspace closed, cmux quit): nothing is lost — cd <project> && crate open brings it back.

07 · When something's off

Plain answers to the five things that happen

You seeWhat it means · what to do
“REFUSING to boot: agent not ready” An agent's sign-in isn't usable. The message names the agent and the exact fix — usually: run it once in a plain terminal, /login, and click Always Allow on any keychain dialog. Then Boot again.
A seat answers “API Error: 401 / run /login” Its sign-in went stale mid-session (overnight is typical). /login in that pane, then use the dashboard's Relaunch on that seat — a running session can't pick up new credentials by itself.
The app window vanished The workspace (or cmux) was closed. State is safe: cd <project> && crate open.
“has no .agents/bin — is the engine attached?” The path isn't an attached project (typo, or a folder that never finished attach). Open the Attach screen and attach the real folder — attaching an already-attached project is safe and heals links.
“update available” on Welcome Click Update now (your customizations survive), then restart the app when asked (close the Crate Engine workspace, crate open).

A rule that runs through all of it: Crate Engine refuses loudly and tells you the one line that fixes it. If a screen ever lies, stalls, or leaves you stuck with no next step — that's a bug we want reported, not something to work around.
